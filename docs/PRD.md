# Shiproof — Product Requirements Document

> **Emotional Hook**: Founders ship code but forget to tweet about it. Proof of Ship is the hottest narrative but nobody automates it.

## Problem Statement
Developers push code daily but never publicize their progress. Manual tweeting is friction.

## Solution Overview
GitHub webhook → AI summarizes commit → SagaPad skill auto-drafts X post.

## Core Features (MVP)
1. GitHub webhook listener
2. OpenAI commit summarizer
3. SagaPad skill manifest
4. X API draft post

## Success Metrics
- All SDK features demonstrably integrated
- Demo flow works end-to-end

## Out of Scope
- ❌ Multi-repo
- ❌ Analytics
- ❌ Thread generation
